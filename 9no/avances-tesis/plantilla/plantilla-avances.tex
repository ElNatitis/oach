\section{Objetivos}
\subsection{Generales}
\begin{frame}{Objetivo general.}
	\begin{block}{}
		Caracterizar géneros musicales mediante el análisis estadístico de sus propiedades musicales (pitch, ritmo e intensidad), aplicando técnicas de análisis de series temporales como el Análisis de Fluctuaciones sin Tendencia (DFA) y sus variantes, con el fin de generar una base cuantitativa que permita, en un futuro, determinar la pertenencia de una canción a un género específico.
	\end{block}
\end{frame}
\subsection{Específicos}
\begin{frame}{Objetivos específicos. (1/2)}
	\begin{block}{1 - Desarrollar herramientas automatizadas}
		Interactuar con la API de \textit{MusicBrainz} para recopilar listas de canciones clasificadas de forma fiable por género musical.
	\end{block}
	\begin{block}{2 - Extraer y construir series temporales multivariadas.}
		Una canción, a nivel de datos, es un conjunto de series de tiempo multivaluadas (instrumentos) con 3 variables (pitch, ritmo y volumen). Se construye a partir de archivos MIDI.
	\end{block}
\end{frame}

\begin{frame}{Objetivos específicos. (2/2)}
	\begin{block}{3 - Aplicar y adaptar la metodología de Gustavo Mekler}
		Análisis de flutuación sin tendencia para medir autocorrelaciones lineales y no lineales en dichas series temporales.
	\end{block}
	\begin{block}{4 - Diseñar un procedimiento replicable.}
		Para extender el análisis a múltiples géneros musicales más allá del caso inicial (salsa).
	\end{block}
\end{frame}

\begin{frame}{\textit{MusicBrainz}}
	\begin{block}{En general}
		\begin{itemize}
			\item Es una enciclopedia musical de código abierto creada en 2000 por Robert Kaye.

\begin{frame}{Funcionamiento de los programas}
\begin{block}{Módulo 1 – Integración de la serie}
\begin{itemize}
    \item Se calcula el promedio de cada serie (tono, volumen, duración).
    \item Se construye la serie integrada restando el promedio y acumulando valores.
    \item Transforma los datos originales en una caminata acumulada (base del DFA).
\end{itemize}
\end{block}
\end{frame}

\begin{frame}{Funcionamiento de los programas}
\begin{block}{Módulo 2 – Segmentación}
\begin{itemize}
    \item Se divide la serie integrada en segmentos de tamaño $s$.
    \item Cada segmento se guarda para ser comparado más adelante.
    \item Prepara los datos para analizar fluctuaciones locales a distintas escalas.
\end{itemize}
\end{block}
\end{frame}

\begin{frame}{Funcionamiento de los programas}
\begin{block}{Módulo 3 – Simulación de segmentos}
\begin{itemize}
    \item Para cada segmento, se ajusta un polinomio de grado 2 (usando Cramer).
    \item Se genera una versión suavizada o simulada del comportamiento del segmento.
    \item Representa la tendencia local de los datos.
\end{itemize}
\end{block}
\end{frame}

\begin{frame}{Funcionamiento de los programas}
\begin{block}{Módulo 4 – Cálculo de fluctuaciones}
\begin{itemize}
    \item Se compara cada segmento real con su versión simulada.
    \item Se suman las diferencias cuadráticas medias.
    \item Se obtiene la magnitud promedio de las fluctuaciones $F(s)$ para cada escala $s$.
\end{itemize}
\end{block}
\end{frame}
